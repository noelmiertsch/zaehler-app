# Zählerablesung Burgkemnitzer Str. 6

Lokale PWA für den Zähler-Rundgang. Alle Daten (Zählerliste, Ablesungen, Fotos) bleiben auf dem iPhone. Im Repository liegt nur der App-Code – keine Zählernummern, Stände oder Namen.

- App: https://noelmiertsch.github.io/zaehler-app/
- Update veröffentlichen: geänderte Dateien hochladen und immer `VERSION` in `sw.js` (und `APP_VERSION` in `app.js`) erhöhen – dann zeigt die App „Neue Version verfügbar“.
- Ausführliche Anleitung: Documents/Software und Apps/Zählerablesung BuKe 6/Entwicklung/README.md
